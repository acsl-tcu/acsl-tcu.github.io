# HP の更新方法（学生向け）

メンバー表と集合写真はブラウザから更新できます。保存した内容は先生が確認してから公開されます。

## 初回だけ

1. GitHub アカウントで <https://app.pagescms.org> にログインする
2. `acsl-tcu/acsl-tcu.github.io` を開く

## 更新手順

1. 画面上部のブランチを **`content`** に切り替える（`main` には保存できません）
2. 「メンバー」を開き、年度を選ぶ（新年度は「Add an entry」で作成し、年度を入力）
3. メンバーを追加・修正する
   - 氏名（日本語／英語）、学年・職位、研究テーマ（日本語／英語）
   - 学年・職位は一覧から選ぶ
4. 集合写真をアップロードする（写真が未設定の年度はサイトに表示されません）
5. 「Save」を押す

保存すると自動でチェックが走り、問題がなければ先生宛ての PR（変更の確認依頼）が作られます。
チェックでエラーになった場合は、GitHub の Actions タブ「Content check」に理由が表示されるので、修正して保存し直してください。

## 注意

- 写真は 8MB 以下にする（長辺 2000px 程度の JPG/PNG を推奨）
- 英語氏名は「名 姓」の順（例: Taro Tokyo）
