# HP の更新方法（学生向け）

メンバー・業績・研究テーマ・講義はブラウザから更新できます。保存した内容は先生が確認してから公開されます。

## 編集画面を開く

**<https://app.pagescms.org/acsl-tcu/acsl-tcu.github.io/content>**

- 初回は GitHub アカウントでログインする
- 必ず `content` ブランチで編集する（上のリンクを開けば最初から `content` になっています。`main` には保存できません）
- 左のサイドバーから「メンバー」「業績」「研究テーマ」「講義」を選ぶ

## 更新するもの

| 項目 | 単位 | 主な入力 |
|---|---|---|
| メンバー | 年度ごと | 氏名（日・英）、学年・職位（一覧から選択）、研究テーマ（日・英）、集合写真 |
| 業績 | 発表年ごと | 論文誌／国際会議／国内発表の各リスト。年月は `YYYYMM`（例: 202603）で、発表年と一致させる |
| 研究テーマ | 1 テーマ 1 件 | タイトル・概要（日・英）、種類（手法／応用）、応用分野、図・動画（最大 4 件表示） |
| 講義 | 年度ごと | 講義コード、科目名（日・英）、開講期、担当教員 |

新しい年度・発表年は、一覧画面の「Add an entry」で作成し、年度（年）を入力します。

## 保存したあと

「Save」を押すと自動でチェックが走り、問題がなければ先生宛ての PR（変更の確認依頼）が作られます。
チェックでエラーになった場合は、GitHub の Actions タブ「Content check」に理由が表示されるので、修正して保存し直してください。

## 注意

- 集合写真は 8MB 以下（長辺 2000px 程度の JPG/PNG を推奨）。未設定でもメンバー表は表示されます
- 研究の動画はできるだけ小さく（目安 10MB 以下）
- 英語氏名は「名 姓」の順（例: Taro Tokyo）
- 業績の DOI は `10.xxxx/...` の形、または URL をそのまま入力
